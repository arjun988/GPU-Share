# Completions

Generate:

```bash
gpumesh completion bash > ~/.local/share/bash-completion/completions/gpumesh
gpumesh completion zsh > "${fpath[1]}/_gpumesh"
gpumesh completion fish > ~/.config/fish/completions/gpumesh.fish
gpumesh completion powershell >> $PROFILE
```

Or evaluate once:

```bash
source <(gpumesh completion bash)
```
